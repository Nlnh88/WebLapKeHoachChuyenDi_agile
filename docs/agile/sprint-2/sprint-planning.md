## 2. Sprint Goal

Trong Sprint 2, nhóm tập trung hoàn thiện các chức năng phía quản trị
và ổn định hệ thống trước khi kết thúc dự án.

Các mục tiêu chính:

- Xây dựng Dashboard User.
- Quản lý tài khoản người dùng.
- Thêm, sửa và xóa địa điểm du lịch.
- Quản lý trạng thái chuyến đi.
- Phân quyền người dùng và quản trị viên.
- Kiểm thử các chức năng User/Admin.
- Sửa lỗi và tích hợp hệ thống.
- Thực hiện kiểm thử cuối cùng.

## 5. Definition of Done

Một task được xem là hoàn thành khi:

- [ ] Chức năng đã được lập trình.
- [ ] Giao diện hoạt động đúng.
- [ ] Dữ liệu được lưu trữ và truy xuất đúng từ MySQL.
- [ ] Chức năng được kiểm thử trên môi trường XAMPP.
- [ ] Phân quyền được kiểm tra đối với các chức năng liên quan.
- [ ] Không còn lỗi nghiêm trọng.
- [ ] Code được tích hợp vào project.
- [ ] Code được cập nhật lên GitHub.
